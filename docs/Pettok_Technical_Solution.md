# 抖音宠物 (Pettok) - 技术方案

## 1. 项目概述
“Pettok” 是一个基于开源仿抖音短视频前端项目（Vue 3 + Vite）深度定制的创新功能模块。它旨在通过一只名为“Pettok”的虚拟宠物，以数据仪表盘、情感信件、宠物社交和智能对话等形式，将用户在平台上的观看行为（如观看时长、情绪偏好、内容分类）进行拟人化和具象化的反馈，从而提供一种“耳伴感足、宠物感强”的情感陪伴体验。

## 2. 核心技术栈
- **框架**：Vue 3 (Composition API, `<script setup>`)
- **构建工具**：Vite
- **样式**：Less / CSS3 (Flexbox, Grid, CSS Animation)
- **状态管理**：Vue 响应式系统 (`ref`, `computed`, `inject`)
- **动效**：CSS 帧动画 (`steps()`), CSS 渐变与玻璃拟态 (`backdrop-filter`)

## 3. 核心功能与实现方案

### 3.1 虚拟宠物渲染 (CSS 帧动画)
- **挑战**：原项目中使用的 Live2D/WebGL 在复杂的虚拟列表（SlideList）滚动时，容易出现性能开销过大、白屏和渲染丢失的问题。
- **解决方案**：放弃重量级的 WebGL，采用纯 CSS 的**雪碧图帧动画（Sprite Animation）**。
- **实现细节**：
  - 将宠物模型转换为 `.webp` 格式的雪碧图（例如 `560px x 700px`，分为 8 列 10 行）。
  - 使用 CSS `animation: cat-idle 2s steps(6) infinite;` 结合 `background-position` 的变化，实现轻量、流畅且绝对稳定的猫咪呼吸、眨眼等待机动作。
  - 根据视频滑动索引 (`index`)，利用 Vue 的 `computed` 属性，动态切换“有帽子”与“没帽子”两套不同状态的猫咪素材，无缝嵌入在视频播放流中。

### 3.2 极致的一屏自适应排版
- **挑战**：用户要求在不使用滚动条（`overflow: hidden`）且不遮挡抖音原生顶部导航（如“推荐/同城”）的前提下，在一个手机屏幕内完美展示极度丰富的数据卡片（包含基础统计、分类占比、多段式进度条、健康雷达等）。
- **解决方案**：采用**空间极限压缩与 Flexbox 弹性布局**策略。
- **实现细节**：
  - **外层容器避让**：通过给 `feedme-card-overlay` 容器设置精确的 `padding-top: 100px`，使整体卡片下移，避开抖音原生顶部 UI。
  - **内容压缩**：大幅压缩字号（缩小至 `9px~13px`）、内外边距（`padding` 和 `gap`）以及图标/头像尺寸。
  - **布局重构**：将原本纵向堆叠的模块改为**左右分栏布局**（如“今日饮食”的分类排行和深度洞察并排显示）。利用 `justify-content: space-evenly` 让浏览器自动榨干最后一点纵向留白，实现完美的一屏展示。

### 3.3 玻璃拟态与高级感 UI 设计
- **主题风格**：摒弃与抖音原生白色 UI 冲突的亮色主题，采用具有高级感和温度感的深咖啡色调渐变背景（`radial-gradient`）。
- **玻璃拟态 (Glassmorphism)**：在卡片模块、聊天弹窗和背景遮罩中大量使用 `background: rgba(X,X,X,0.X)` 配合 `backdrop-filter: blur(Npx)`，营造出磨砂玻璃般的高级半透明质感。
- **动态微交互**：为“宠物圈”的好友头像增加带有渐变色的底托和代表在线状态的“绿色小圆点”。点赞按钮采用极简的药丸状设计，辅以状态切换反馈。

### 3.4 交互功能拓展
- **详情弹窗 (Modal)**：
  - 在“今日来信”模块中，用户点击“查看详情”可触发 Vue `<transition name="fade">` 动画弹窗。
  - 弹窗内通过响应式数据动态渲染长文本段落，保证卡片外观简洁的同时不丢失深度阅读内容。
- **宠物圈图片放大预览**：
  - 为宠物圈动态的头像绑定点击事件，提取图片的源路径和原有的特殊样式（如渐变背景、缩放比例），在全屏的黑色半透明遮罩中等比例放大展示。
- **智能聊天对话系统**：
  - 在主卡片的宠物旁边增加悬浮的“💬”按钮。
  - 弹窗内置简易的聊天界面，模拟真实对话体验。
  - **事件冲突解决**：因卡片处于抖音的滑动视频组件内，底层拦截了触摸和点击事件。通过给弹窗和输入框精准添加 `@touchstart.stop`、`@mousedown.stop` 和 `@pointerdown.stop`，并强制覆盖 `pointer-events: auto` 和 `user-select: auto`，成功穿透了底层滑动组件的事件屏蔽，恢复了输入框的聚焦与打字能力。
  - **规则引擎**：使用 `setTimeout` 模拟回复延迟，内置基于关键词匹配（如“喵”、“吃”、“代码”）的条件分支，实现具备情绪价值的自动化拟人回复。

### 3.5 视频流 Mock 数据劫持与替换
- **需求**：需要将卡片出现前的前置视频替换为指定的 AI 学习类视频，以呼应卡片内的数据分析（如“今日摄入 60% AI科技”）。
- **实现方案**：
  - 将提供的 `.mp4` 视频存入 `public/videos/`。
  - 在 `src/mock/index.ts` 中拦截默认的数据生成逻辑。
  - 针对前 3 个视频（索引 0、1、2），强行替换其 `url_list`、`author.nickname` 和 `desc`，使其在业务上表现为真实的定制化内容推荐流。

## 4. 总结
本技术方案通过轻量级的 CSS 帧动画解决了 WebGL 渲染痛点，通过极致的 Flexbox 空间压缩实现了复杂数据的单屏展示，并巧妙地通过事件修饰符解决了嵌套滑动组件内的表单输入冲突。最终构建出一个极具沉浸感、高级感和情感陪伴价值的“抖音虚拟宠物”体验模块。
